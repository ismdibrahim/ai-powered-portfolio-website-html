# Toolkit logo assets

Brand SVG marks downloaded from Simple Icons (https://simpleicons.org/) through its CDN:

- WordPress: https://cdn.simpleicons.org/wordpress/21759B
- WooCommerce: https://cdn.simpleicons.org/woocommerce/96588A
- Elementor: https://cdn.simpleicons.org/elementor/92003B
- PHP: https://cdn.simpleicons.org/php/777BB4

Multicolor Figma mark: https://www.vectorlogo.zone/logos/figma/figma-icon.svg

These assets remain the trademarks of their respective owners. The site uses local copies in a static, responsive row. A muted gray CSS filter makes the marks readable on the light page background; hover and keyboard focus restore their brand colors without adding a background box. WooCommerce and PHP SVG view boxes are cropped to remove the source icons' unused vertical space without changing their artwork.
